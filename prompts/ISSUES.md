# Issue triage

Read the report and discussion, then open the guide matching the remaining request. Before returning any issue assessment, read [EVIDENCE.md](EVIDENCE.md), [REPORT.md](REPORT.md), and the type guide matching your final classification. If the classification changes, read its new route too. Read [SCOPE.md](SCOPE.md) before citing an `issue_decision`.

| Category | Guide |
| --- | --- |
| Bug: existing or documented behavior fails | [ISSUE-BUGS.md](ISSUE-BUGS.md) |
| Small enhancement within existing functionality | [ISSUE-CHANGES.md](ISSUE-CHANGES.md) |
| Large feature, new integration/workflow, or unclear product boundary | [ISSUE-FEATURES.md](ISSUE-FEATURES.md) |
| Usage question or unclear intended behavior | [ISSUE-SUPPORT.md](ISSUE-SUPPORT.md) |
